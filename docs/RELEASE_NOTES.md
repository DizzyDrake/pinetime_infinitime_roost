# Roost RC2 — release notes

Roost adds haptic breathing to PineTime running InfiniTime 1.16.0.

**Included:** Box, 4:7:8, and 2:8 presets; custom patterns with up to four phases and zero-second Skip; persistent pattern selection; haptic cues while the screen sleeps; automatic stop for calls, watch alarms, and physical exit; original Roost launcher artwork.

**Compatibility:** This package updates the complete InfiniTime application firmware. Paint and Metronome remain included. The source integration targets InfiniTime commit `0fabfe99d9115c5e258a14fd0c985d300ee41f2d`.

**Install:** Download the DFU ZIP from the [GitHub Release](../../../releases/latest) and follow the [Gadgetbridge guide](INSTALL_GADGETBRIDGE.md). Validate the firmware on the watch after installing.
