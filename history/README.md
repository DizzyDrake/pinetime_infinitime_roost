# Roost's development record

These are the seven original source patches used to assemble the RC2 candidate. They are kept here for studying changes and preserving provenance, **not** as installation instructions.

The current runtime source is in `src/`; `tools/install_into_infinitime.py` handles integration automatically. `integration/changes/` contains only the minimal existing-file touchpoint diffs used by that tool.

The full original source-packet archive is retained separately in the project records; the public repository keeps the patches and an approachable history instead of outdated build-status documents.

RC2 source development included collaboration between Aurora, GPT-6, and Work Queue agents. Aurora's original icon SVG remains byte-for-byte unchanged.
